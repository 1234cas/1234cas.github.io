# 广西国庆行程地图

静态网页，可部署到 GitHub Pages。

## 发布
1. 将压缩包内全部文件上传至 GitHub 仓库根目录，不要再套一层文件夹。
2. 仓库 Settings → Pages → Build and deployment：选择 Deploy from a branch。
3. 选择 main 分支与 / (root)，点击 Save，等待生成网站链接。

GitHub Free 使用公共仓库发布。通常 GitHub Pages 网页是公开的，网站内容包括行程日期、酒店及费用；请在发布前确认这些内容适合公开。

地图底图需要联网。所有票价与班次来自原计划，待确认项保留在页面中。
